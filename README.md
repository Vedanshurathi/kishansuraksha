# 🌾 Kishan Suraksha AI - Agricultural Intelligence Platform

An AI-powered agricultural advisory system designed to empower Indian farmers with technology-driven insights and real-time information.

## 🎯 Overview

Kishan Suraksha AI (KSA) leverages artificial intelligence and machine learning to provide farmers with personalized agricultural advisory, weather forecasts, crop disease detection, market price information, and government scheme details all in one platform.

## ✨ Core Features

- 🤖 **AI-Powered Advisory** - Personalized crop recommendations
- 🌤️ **Real-Time Weather** - Hyperlocal forecasts with alerts
- 📈 **Market Intelligence** - Live commodity prices and trends
- 🔬 **Disease Detection** - Image-based crop disease identification
- 🎓 **Expert Guidance** - Video tutorials and best practices
- 🏛️ **Government Schemes** - Subsidies and support information
- 💰 **Financial Tools** - ROI and crop planning calculators
- 📰 **Agricultural News** - Latest updates in farming sector

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Git
- API keys for OpenWeather and NewsAPI

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/Vedanshurathi/kishansuraksha.git
cd kishansuraksha
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment Variables
```bash
cp .env.example .env
```

Edit `.env` file with your API keys

### 4. Start Server
```bash
npm start
```

Access at: `http://localhost:5000`
